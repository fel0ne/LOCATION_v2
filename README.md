# 🛰️ GPS Tracking & Map Visualization System

Система для приема, хранения и визуализации GPS-данных в реальном времени с отображением на оффлайн/онлайн картах. Разработано как высокопроизводительное решение на C++ для мониторинга подвижных объектов.

## 🚀 Основные возможности
* **Прием данных**: Высокопроизводительный прием координат через ZeroMQ (ZMQ).
* **Хранение**: База данных PostgreSQL с использованием логики Upsert (автоматическое обновление существующих точек по географической сетке grid_key).
* **Визуализация**: Интерактивная карта на базе ImGui и ImPlot.
* **Кэширование**: Многопоточная загрузка тайлов карт с автоматическим управлением видеопамятью (GPU VRAM).
* **Отображение трека**: Визуализация пройденного пути с эффектом пульсации текущей позиции.

## 🛠 Технологический стек
* **Язык**: C++ 17
* **Графика**: OpenGL, GLFW, ImGui, ImPlot
* **Сеть**: ZeroMQ (ZMQ), CPR (C++ Requests)
* **БД**: PostgreSQL (через библиотеку libpqxx)
* **Работа с изображениями**: stb_image

## 🏗 Архитектура системы
1. Data Ingestor: Фоновый процесс, принимающий JSON-пакеты и выполняющий SQL-запросы.
2. Map Engine: Модуль отрисовки, преобразующий географические координаты в экранные пиксели и тайлы.
3. Tile Loader: Система асинхронной загрузки (std::thread), исключающая блокировки графического интерфейса.
4. Memory Manager: Механизм контроля видеопамяти, очищающий старые текстуры при превышении лимита (500+ объектов).

## 📂 Структура базы данных
Используется таблица location_history с уникальным индексом по grid_key для исключения избыточности.

## Зависимости для Linux (Ubuntu / Linux Mint)

Перед сборкой проекта необходимо установить системные библиотеки (PostgreSQL клиент, GLEW, Meson и компоненты X11/Wayland для SDL3):

```bash
sudo apt update && sudo apt install -y libpq-dev meson ninja-build libglew-dev libasound2-dev libxcursor-dev libxi-dev libxinerama-dev libxkbcommon-dev libxss-dev libxtst-dev libwayland-dev libegl1-mesa-dev libgbm-dev libdrm-dev libdbus-1-dev libibus-1.0-dev
```
Команды для сборки:

```bash
mkdir build && cd build
cmake ..
make
```
